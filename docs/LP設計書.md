# バイブコーディング短期講座 LP設計書

## 1. LPの目的とターゲット

### 目的
- バイブコーディング短期講座への申し込み獲得
- 無料体験・説明会への誘導

### ターゲットペルソナ

| 属性 | 詳細 |
|------|------|
| 年齢 | 25〜45歳 |
| 職業 | 非エンジニア（マーケター、企画職、経営者、フリーランス） |
| 課題 | アイデアはあるがプログラミングができない、外注コストが高い |
| 動機 | 自分でアプリやサービスを作りたい、業務効率化したい |
| 不安 | プログラミングは難しそう、続けられるか不安 |

## 3. 各セクションのコンテンツ要素

### 3.1 ヘッダー
```
要素:
├── ロゴ（左）
├── ナビゲーションメニュー（中央）
│   ├── 特徴
│   ├── カリキュラム
│   ├── 料金
│   └── FAQ
└── CTAボタン「無料体験に申し込む」（右）
```

**仕様:**
- 固定ヘッダー（スクロール時も表示）
- 背景: 半透明ダーク
- モバイル: ハンバーガーメニュー

---

### 3.2 ヒーローセクション
```
要素:
├── キャッチコピー
│   └── 「AIと会話するだけで、アプリが作れる時代。」
├── サブコピー
│   └── 「プログラミング経験ゼロでも、たった2週間で自分のアイデアを形にできる
│         バイブコーディング短期集中講座」
├── CTAボタン
│   ├── プライマリ: 「無料体験に申し込む」
│   └── セカンダリ: 「講座の詳細を見る」
├── 実績バッジ
│   ├── 「受講者満足度 98%」
│   ├── 「累計受講者 500名突破」
│   └── 「最短2週間で習得」
└── ビジュアル
    └── AIとの対話でコードが生成されるアニメーション風イメージ
```

**デザイン:**
- フルスクリーン
- ダークグラデーション背景
- パーティクルアニメーション

---

### 3.3 課題提起セクション
```
要素:
├── セクションタイトル
│   └── 「こんなお悩みありませんか？」
└── 課題リスト
    ├── 「アイデアはあるのに、プログラミングができなくて形にできない」
    ├── 「外注すると高額で、思い通りのものが作れない」
    ├── 「プログラミングスクールに通ったが、挫折してしまった」
    └── 「エンジニアとのコミュニケーションがうまくいかない」
```

**デザイン:**
- アイコン付きリスト
- ネガティブな感情を表す暗めの配色

---

### 3.4 解決策セクション
```
要素:
├── セクションタイトル
│   └── 「バイブコーディングなら、すべて解決できます」
├── バイブコーディングとは
│   └── 説明テキスト + 図解
├── 3つのポイント
│   ├── 「自然言語でAIに指示するだけ」
│   ├── 「コードを書く必要なし」
│   └── 「修正も会話で完結」
└── デモ動画/GIF
    └── 実際の開発プロセスを見せる
```

**デザイン:**
- 明るい配色に切り替え
- ビフォーアフター形式

**デザイン:**
- グリッドレイアウト（3列）
